# KinderEdit AI Web Interface Design

Design a modern, minimalist web application called **KinderEdit AI**, an AI-assisted multi-camera kindergarten graduation video editing platform.

## Overall Design Philosophy

The interface should feel:

- Calm
- Professional
- Safe
- AI-assisted but human-controlled
- Suitable for teachers with minimal technical background

Avoid looking like a complex video editor such as Adobe Premiere Pro.

Focus on a clean workflow dashboard experience.

## Design Language

Modern SaaS Dashboard

Inspired by:

- Linear
- Notion
- Stripe Dashboard
- Microsoft Copilot
- Framer

Use:

- Rounded corners (16px)
- Soft shadows
- Glassmorphism panels
- Smooth gradients
- Plenty of whitespace
- Minimal visual clutter

The overall feeling should be:

"Trustworthy AI Assistant for Teachers"
